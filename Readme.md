# localrepo

A minimal HTML/CSS test page used to practice creating a repository and pushing it to GitHub from the command line.

## Overview

A one-paragraph page with a single style rule (`p { color: red }`). Serves purely as a Git/GitHub workflow exercise, not as an application.

## Tech Stack

- HTML
- CSS

## Getting Started

Open `index.html` in any browser.
